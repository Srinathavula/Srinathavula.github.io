## 1. 🚦 Density-Based Smart Traffic Control System

**Domain:** Image Processing · Intelligent Transportation  
**Project Year:** 2022

### 📖 Overview

The Density-Based Smart Traffic Control System explores the use of digital image processing to support traffic-signal decisions based on traffic density. The project focuses on **Canny Edge Detection** and traffic-image analysis to investigate an alternative to conventional fixed-time traffic signals.

### 🎯 Objectives

- Explore image-processing techniques for traffic-scene analysis.
- Apply Canny Edge Detection to identify edges in traffic images.
- Investigate traffic-density estimation using processed image information.
- Explore traffic-signal allocation based on estimated traffic density.
- Study the application of computer vision concepts to intelligent transportation systems.

### ⚙️ Working Principle

1. **Traffic Image Input:** Use traffic-scene images as input for analysis.
2. **Image Processing:** Prepare the images for further processing.
3. **Edge Detection:** Apply Canny Edge Detection to identify image edges.
4. **Image Comparison and Analysis:** The project report describes comparing traffic images with an empty-road reference image and counting white pixels as part of its analysis.
5. **Signal Allocation:** Use the analyzed traffic information in the proposed traffic-signal allocation logic.

### 🛠️ Technologies and Concepts

- Python
- Digital Image Processing
- Canny Edge Detection
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Traffic Image Analysis

*Note: The report mentions these technologies and concepts, but the exact role of every library should be confirmed against the original source code.*

### 💡 Project Significance

- Investigates traffic-aware signal allocation.
- Demonstrates an academic application of image processing.
- Explores how traffic images can inform transportation-management decisions.

## 2. 🤰 MamaBot: AI-Based Chatbot System Supporting Families and Women During Pregnancy

**Domain:** Artificial Intelligence · Natural Language Processing · Healthcare Information Support  
**Project Year:** 2023

### 📖 Overview

MamaBot is an academic project focused on a chatbot concept intended to help pregnant women, mothers, and families with young children access general pregnancy- and childcare-related information through a conversational interface.

The project explores the use of AI-related techniques and natural language processing to support users seeking relevant information and guidance.

### 🎯 Objectives

- Explore a conversational interface for pregnancy-related information.
- Provide a platform for users to submit questions and receive responses.
- Investigate the application of Natural Language Processing (NLP) in chatbot development.
- Explore the use of an LSTM model and structured JSON data, as identified in the project materials.
- Study the potential role of chatbots in making general health information more accessible.

### ⚙️ High-Level Workflow

1. **User Interaction:** The user enters a question through the chatbot interface.
2. **Input Handling:** The application receives the user's text.
3. **Query Processing:** The proposed system explores language-processing and AI-related approaches.
4. **Response Handling:** The application uses its configured data and response logic.
5. **Response Display:** The chatbot interface presents a response to the user.

*The report describes the proposed AI/NLP approach, but does not fully establish the implemented model architecture, training procedure, dataset provenance, or measured model accuracy.*

### 🛠️ Technologies and Concepts

- Python 3.7
- Django
- Natural Language Processing (NLP)
- Long Short-Term Memory (LSTM), identified in the project description
- JSON-based data
- HTML and JavaScript for the described interface

*These technologies are drawn from the project documentation. The precise implementation of each component should be verified against the original source code.*

### 💡 Project Scope

- Pregnancy-related information support.
- General maternal and childcare information.
- Conversational user interaction.
- Exploration of AI-assisted information access.
- Potential future extensions such as multilingual support, personalization, postpartum support, and mental-health information resources.

### 🩺 Responsible Use

MamaBot is an academic project and should not be treated as a clinically validated medical tool. Its responses are not a substitute for professional medical advice, diagnosis, or treatment. Medical concerns should be discussed with a qualified healthcare professional.
